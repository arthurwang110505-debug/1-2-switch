# 1-2-Switch Clone Game

A fast-paced, party-style local multiplayer game inspired by *1-2-Switch*, designed for quick matches, face-to-face interaction, and playful competition. This project reimagines classic motion- and audio-driven minigames for modern web or desktop platforms using lightweight, responsive web technologies.

---

## 🎮 Features

* **Face-to-Face Gameplay:** Designed to be played with friends in the same room—look them in the eye, not just at the screen!
* **Quick-Fire Minigames:** Fast rounds ranging from reaction tests to rhythm showdowns and bluffing duels.
* **Audio-First Design:** Immersive sound cues and voice prompts allow players to focus on their opponent rather than staring at a UI.
* **Lightweight & Cross-Platform:** Built using web technologies, making it easy to run directly in a browser or package via Electron.

---

## 🕹️ Included Minigames (Concept)

1. **Quick Draw (快槍手):** A classic Western standoff. Wait for the audio signal ("FIRE!"), then click or press your button faster than your opponent.
2. **Copycat Dance (有樣學樣):** Replicate a sequence of poses or rhythm beats matching your opponent's timing.
3. **Safe Cracker (轉開保險箱):** Listen closely to the subtle audio clicks to find the correct combination before the timer runs out.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed on your local machine:
* **Node.js** (v16.0 or higher recommended)
* **npm** or **yarn**

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/1-2-switch-clone.git
   cd 1-2-switch-clone
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (or Framework of choice like React / Vue)
* **Audio API:** Web Audio API for low-latency sound effect playback and speech synthesis
* **Styling:** Tailwind CSS for clean, responsive UI design

---

## 🎯 How to Play

1. Gather two players and position yourselves facing each other with the screen visible or placed between you.
2. Select a minigame from the main menu.
3. Follow the on-screen audio/visual cues.
4. The player with the fastest reflexes, best rhythm, or sharpest wits wins!
